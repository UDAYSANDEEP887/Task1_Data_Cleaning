# Task 1 - Data Cleaning

## Objective
Clean and preprocess the customer dataset using Python and Pandas.

## Dataset
The dataset contains 2240 customer records and 29 columns.

## Data Cleaning Performed
- Loaded the customer dataset using Pandas.
- Checked for missing values.
- Handled missing Income values.
- Checked for duplicate rows.
- Standardized column names to lowercase.
- Converted Dt_Customer to datetime format.
- Verified final data types.
- Verified missing values after cleaning.
- Verified duplicate records after cleaning.
- Saved the cleaned dataset as `cleaned_customer_data.csv`.

## Results

- Original dataset shape: 2240 rows × 29 columns
- Final dataset shape: 2240 rows × 29 columns
- Missing values before cleaning: 24
- Missing values after cleaning: 0
- Duplicate rows before cleaning: 0
- Duplicate rows after cleaning: 0
